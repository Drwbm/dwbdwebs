# DWBW Web Makers

Static website for DWBW Web Makers / Angel Danny Liche.

## Files
- `index.html` — main website
- `styles.css` — responsive styling
- `script.js` — menu and browser settings
- `images/logo.png` — supplied DWBW/Danny Liche logo
- `_headers` — Netlify security headers

## Publish
Upload the entire folder to a static host such as GitHub Pages or Netlify.

## Security
The site avoids server-side credentials and forms, uses a strict content-security policy, disables framing, and adds common security headers when hosted on a platform that supports `_headers`.

Important: no static website can guarantee absolute security. Hosting, domain, DNS, account passwords, and third-party services must also be secured.
